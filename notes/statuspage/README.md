# Atlassian Statuspage

Behavior of the public, unauthenticated API that [Atlassian Statuspage](https://www.atlassian.com/software/statuspage) pages serve under `/api/v2/`.

- [public-api.md](./public-api.md): endpoints, incident ID shape, update fields and timestamp offsets, 404 responses, and caching, observed on live pages.
- [impact.md](./impact.md): how incident impact and the page indicator are computed from component statuses, and how often each impact occurs.
